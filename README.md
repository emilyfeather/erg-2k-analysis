# erg-rankings-analysis
I extracted the 2,000 fastest 2k times for both female and male rowers from Concept2's 2026 official rankings and have performed some analysis to answer some of my own thoughts and questions.

I wondered whether this dataset would display bunching at times just below round numbers, where athletes had set goals and calculated precise splits to hold throughout the 2000m to beat specific 'goal times' (as I knew this was something I personally do!). It was pretty obvious at the 7 minute mark for the men, but not so much for the women where large fluctuations were distributed quite randomly within each 30 second time period.
